## 🧠 How I Approach Engineering

- **Investigate before fixing.** Use evidence, logs, network activity, database queries, and source code to understand failures.
- **Think across the system.** Trace behavior through interfaces, application logic, authentication, background processes, and persistence.
- **Understand before changing.** Evaluate existing architecture, dependencies, business rules, and compatibility constraints.
- **Design for failure.** Consider unexpected states, concurrency, performance, reliability, and recovery.
- **Validate the result.** Test assumptions, verify behavior, and account for regressions.
- **Communicate decisions.** Explain findings, trade-offs, limitations, and technical reasoning.

## 🚀 What I'm Building

### T-CORE Diagnostics

**Cross-platform hardware diagnostics and technical evidence system**

An independent software project designed to coordinate hardware diagnostic tests, supervise execution conditions, preserve evidence, and support technical workflows.

Its documented 1.0.1 distribution includes:

- **Local:** Diagnostics on a single computer.
- **Station:** Background agent for workshop-managed devices.
- **Central Docker:** Web-based coordination of diagnostic jobs over a local network.
- **Windows and macOS:** Platform-specific diagnostics using supported hardware providers.
- **Controller, Guardian, and Agent:** Separate responsibilities for coordination, safety supervision, and test execution.
- **Hardware testing:** CPU, RAM, GPU, VRAM, storage, and system information.
- **Reliability:** Persistent sessions, controlled cancellation, safety policies, and recovery mechanisms.
- **Evidence:** Structured JSON and technical PDF reports.

The system is designed to distinguish successful tests from unsupported, incomplete, interrupted, or safety-blocked execution.

**Engineering focus:** System-level integration, process isolation, cross-platform development, concurrency, reliability, hardware-aware software, and technical reporting.

*Independent project. The source code is not currently presented as a public repository.*
